Gateway-LLM

Multi-Provider AI Router · Kimi · DeepSeek · GLM · Qwen

VPS belum diset

1. VPS / Backend URL

Alamat VPS tempat kamu men-deploy llm-router. Tanpa ini, web app tidak bisa test koneksi atau chat.

Pastikan VPS kamu sudah pakai Caddyfile dengan CORS * (lihat template deploy). Tanpa CORS, request dari Pages akan ke-block browser.

2. Sesi / Token Provider

Input sesi manual. Token disimpan di localStorage browser kamu saja — tidak pernah dikirim ke server mana pun selain VPS kamu sendiri saat test koneksi.

3. Auto-Generated API Endpoints

URL OpenAI-compatible yang siap dipakai. Update otomatis saat kamu isi sesi/VPS URL.

4. Contoh Kode (Copy-Paste Ready)

Pilih bahasa, pilih provider, klik copy. Tinggal paste ke project kamu.

5. Chat Test (Live)

Test langsung ke VPS kamu. Pastikan VPS sudah jalan + sesi sudah diisi + URL VPS sudah diset.

Pilih provider, ketik pesan, lalu kirim.

6. Download Deploy Package

Generate docker-compose.yml + .env + Caddyfile + deploy.sh yang sudah terisi token kamu. Tinggal scp ke VPS dan jalankan bash deploy.sh.

Setelah download, upload semua file ke VPS, lalu jalankan sudo bash deploy.sh.

⚠️ Catatan Keamanan

  • Token/sesi disimpan di localStorage browser kamu. Tidak ada server backend di web app ini.
  • Saat test koneksi / chat, request dikirim langsung ke VPS yang kamu set — tidak via server mana pun.
  • Pakai akun dummy untuk setiap provider, bukan akun utama.
  • Jika token bocor → sign out dari semua device di provider masing-masing.
  • Endpoint API di VPS tanpa auth. Tambahkan basic_auth di Caddyfile kalau mau dipublik.
